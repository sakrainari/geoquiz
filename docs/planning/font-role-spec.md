# フォント役割表 v1

## 基本方針

- 書体は `2書体` に絞る
- 情報の読みやすさを優先する
- 強調は限定して使う
- 全体は静かで洗練、要所だけゲーム感を出す

## ベース本文書体

- 書体: `Zen Kaku Gothic New`
- 用途:
  - 本文
  - 説明文
  - UIラベル
  - ボタン文言
  - ランキング項目名
  - 分析画面の数値カード
  - 左パネルの見出し
  - 確認マップ系の大見出し
- 印象:
  - 読みやすい
  - 情報整理に強い
  - 日本語UIとの相性が良い

## 強調書体

- 書体: `Dela Gothic One`
- 用途:
  - `GeoQuiz` ロゴ
  - `Clear / Game Over`
  - 市外局番ラベル数字
  - 特別に目立たせたい単独数字
- 印象:
  - ゲームっぽさ
  - ひと目で印象に残る
  - 使いすぎると重くなるため限定使用

## Zen Kaku を使う場所

- スタート画面の説明文
- モードカードのタイトルと説明
- 確認マップの左パネル大見出し
- `今回の結果`
- `累積分析`
- `次にやる`
- ランキング名
- 再出題ボタン
- 分析画面のカード値
- `前回比`
- `自己ベスト`
- 通常の時間表示
- 通常の統計値

## Dela を使う場所

- `GeoQuiz` ロゴ
- `Clear`
- `Game Over`
- 市外局番モードの地図上ラベル
- 広域市外局番モードの地図上ラベル
- 必要ならトップの大きい数値演出の一部

## Dela を使わない場所

- 長い日本語見出し
- 説明文
- ランキング本文
- 分析カードの複合テキスト
  - 例: `前回比 +0.5秒`
- ボタン文言
- 市区町村名の一覧表示
- 確認マップ系の長いタイトル

## 数字の扱い

- 通常の統計数値:
  `Zen Kaku Gothic New` の太字
- 地図上の市外局番ラベル:
  `Dela Gothic One`
- 特別演出の大数字:
  `Dela Gothic One`
- 混在表記:
  - `前回比 +0.5秒`
  - `平均回答 2.1秒`
  は `Zen Kaku Gothic New`
- 理由:
  単位付き数値は可読性優先の方がきれい

## ウェイト方針

- 本文:
  `500` か `700`
- セクション見出し:
  `700` か `900`
- 数値カード:
  `900`
- Dela:
  デフォルトのまま使用

## 画面ごとの適用方針

- スタート画面:
  ロゴだけ `Dela`
  それ以外は `Zen Kaku`
- ゲーム画面:
  市区町村系は `Zen Kaku` 中心
  市外局番ラベルだけ `Dela`
- 終了オーバーレイ:
  `Clear / Game Over` は `Dela`
  成績項目は `Zen Kaku`
- 分析画面:
  ほぼ `Zen Kaku`
  ブランド感はレイアウトと配色で出す

## 目指す印象

- 情報は静かに強い
- 強調は限定的
- 日本語が読みやすい
- いわゆる“ゲームUIすぎる重さ”は避ける
- `Codexらしい` 整理感とシャープさを優先

## 実装優先順

1. 分析画面のカード値を `Zen Kaku` に統一
2. 左パネルの確認マップ大見出しを `Zen Kaku` 化
3. ボタンとランキングの書体統一
4. `Dela` の使用箇所をロゴ・終了見出し・市外局番ラベルへ限定
