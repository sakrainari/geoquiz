# 開始導線仕様書

作成日: 2026-05-23

## 目的

スタート画面の情報量を減らし、クイズ開始前の設定は地図を見ながら行えるようにする。

確認マップの即時性は維持しつつ、クイズ系モードでは「選ぶ」「整える」「始める」を段階化する。

## 基本方針

- スタート画面ではモード選択を主役にする
- クイズ系モードは、選択後に地図付きの準備画面へ遷移する
- 開始前設定と `開始` ボタンは準備画面で表示する
- 確認系モードは従来どおり即表示する

## 対象範囲

この仕様書は以下を対象とする。

- スタート画面から準備画面への遷移
- 準備画面の開始前設定
- カウントダウン
- リスタート

この仕様書は以下を対象外とする。

- 確認マップ系の詳細UI変更
- ブラウザ再読込をまたぐ設定永続化
- カウントダウン秒数のカスタマイズ
- キーボードショートカット

## モード区分

### クイズ系モード

- 市区町村
- 市外局番
- 市外局番（広域）
- パズル

### 確認系モード

- 市区町村マップ
- 市外局番マップ
- 広域局番マップ

## 画面構成

### 1. スタート画面

表示内容:

- クイズ系モードカード
- 確認系モードカード
- 統計情報

表示しないもの:

- 開始前設定
- 大きい `開始` ボタン

役割:

- どのクイズを遊ぶか選ぶ
- 確認マップへ素早く入る

### 2. 準備画面

クイズ系モード選択後に表示する。

表示内容:

- 地図
- 選択中モード名
- 開始前設定
- 大きい `開始` ボタン

役割:

- 地図を見ながら設定を調整する
- バー位置を確認する
- 開始直前の状態を整える

### 3. プレイ画面

`開始` 押下後、`3 → 2 → 1 → Start` のカウントダウンを経てプレイ状態へ入る。

## モード選択の挙動

### クイズ系モード

- スタート画面でカード押下
- 即開始しない
- 準備画面へ遷移する
- 押下したモードを選択状態として保持する

### 確認系モード

- スタート画面でカード押下
- 従来どおり即表示する
- `開始` ボタンは不要

## 開始前設定

準備画面で以下を表示する。

### ルール

- ノーマル
- サドンデス

デフォルト:

- ノーマル

### 音声

- ON
- OFF

デフォルト:

- ON

意味:

- ON のとき、正解時も不正解時も対象名を読み上げる
- OFF のとき、読み上げを行わない

### バー位置

- 左
- 上
- 下
- 右

デフォルト:

- 左

意味:

- 左: 左パネル
- 上: 上バー
- 下: 下バー
- 右: 右パネル

## 開始ボタン

### 表示位置

- 準備画面に大きく表示する
- 設定パネルと同じエリアに置く

### 文言

- `開始`

### 補助表示

必要に応じて、現在の開始対象を小さく表示してよい。

例:

- `市区町村モードを開始`

## デフォルト値

- デフォルトクイズモード: 市区町村
- ルール: ノーマル
- 音声: ON
- バー位置: 左

## 開始時フロー

クイズ系モードでは以下の順で進行する。

1. スタート画面でクイズ系モードを選ぶ
2. 準備画面へ遷移する
3. 地図と設定を確認する
4. `開始` を押す
5. `3 → 2 → 1 → Start`
6. プレイ開始

## カウントダウン仕様

### 表示

- 画面中央に大きく表示する
- 表示順は `3 → 2 → 1 → Start`

### 入力制御

- カウントダウン中は地図クリックを無効にする
- カウントダウン中は回答入力を無効にする
- `Start` 表示終了後に入力を有効化する

### HUD

- HUD は表示したままでよい

## リスタート仕様

### 名称

- ボタン文言は `リスタート`

### 意味

- 現在のゲームを同条件で最初からやり直す

### 保持対象

- 現在モード
- ルール設定
- 音声設定
- バー位置

### 挙動

- 準備画面を経由せず、そのまま同条件で再開始してよい
- ただし再開始時も `3 → 2 → 1 → Start` は表示する

## 設定保持のスコープ

### 今回入れるもの

- ページ滞在中のセッション内保持
- 準備画面からプレイ画面への引き継ぎ
- リスタート後の引き継ぎ

### 今回入れないもの

- ブラウザ再読込後の復元
- 次回訪問時の復元

## UI要件

### スタート画面

- 情報を詰め込みすぎない
- クイズ系カードの選択導線を明確にする
- 確認系は即表示の軽さを優先する

### 準備画面

- 地図が最初から見える
- バー位置変更の結果が視覚的に確認できる
- `開始` ボタンは迷わないサイズと配置にする

## 実装上の注意

- スタート画面の密度を上げすぎない
- 開始前設定は準備画面へ移し、役割を分離する
- 確認系モードに開始導線を持ち込まない
- 既存のレイアウト切替機能と競合しないようにする
- 現在の音声・ルール・バー位置設定を共通状態で持つ

## 完了条件

以下を満たしたら本仕様の実装完了とする。

- スタート画面に開始前設定が常駐していない
- クイズ系モード選択後に準備画面へ遷移する
- 準備画面で地図と設定が同時に見える
- `開始` ボタンは準備画面にある
- 確認系モードは即表示のまま
- `3 → 2 → 1 → Start` が表示される
- `リスタート` で設定を保持したまま再開始できる
