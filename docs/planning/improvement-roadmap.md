# GeoQuiz 改善ロードマップ

作成日: 2026-05-19

## 基本方針

- 今は埼玉版を完成させるフェーズとする。
- 東京追加前に、動作安定、成績保存、ラベル、ヒートマップ、パズル基盤を固める。
- 自動計算は初期値作成用とし、最終的なラベル位置や角度は人力補正できるようにする。
- 単なる地図クイズではなく、GeoGuessr練習ツールとして育てる。
