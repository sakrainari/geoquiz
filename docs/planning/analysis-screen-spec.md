# 分析画面仕様 v2

## 目的

- 1画面で重要情報を把握できる分析画面にする
- `今回の結果` `戦績` `累積分析` `次にやる` を短時間で見渡せる構成にする
- 地図は補助扱いにし、情報を主役にする

## 全体レイアウト

- 左 72%
- 右 28%
- 左側に情報を集約する
- 右側に小さめ地図を置く
- 縦スクロールは極力発生させない

## 今回の結果

- 正解
- ミス
- 一発正解
- 平均回答
- 出題数または到達問題数
- クリアタイムまたは経過時間
- 前回比
- 自己ベスト

## 戦績

- 見出し: `戦績`
- 直近5回の小さな推移を表示する
- クリア時:
  - クリアタイム推移
- Game Over時:
  - 到達問題数推移
- 今回の回を強調する
- ベスト記録が分かるようにする

## 累積分析

- タブ:
  - ミス
  - 正答率
  - 平均時間
- 表示件数は 3〜5 件
- 初期タブは `ミス`

## 次にやる

- ランキングから再出題
- 前回ミスだけ再出題
- 未正解だけ再出題
- 最近ミスだけ再出題
- 低正答率を優先出題

## 右側地図

- 見出しは短くする
- 小さめ固定
- 補助情報として扱う
