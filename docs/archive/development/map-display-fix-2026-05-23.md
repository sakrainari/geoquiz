# 地図表示不具合の対応メモ

2026-05-23 に、ゲーム画面で地図が黒いまま表示されない不具合を修正した時の記録です。

## 症状

- クイズUI自体は表示される
- 問題文やカウンタは動く
- Leaflet の地図部分だけ黒いままになる

## 原因

原因は Leaflet 本体ではなく、ゲーム画面のレイアウトでした。

- 地図データ自体は Leaflet に読み込まれていた
- ただし `#map` の描画領域が `size: { x: 1700, y: 0 }` のように高さ `0` になっていた
- その結果、SVG の `path` は存在していても画面上には見えなかった

加えて、通常モードではゲーム画面がまだ非表示の段階で地図初期化が走る箇所があり、表示タイミングの不安定さもあった。

## 対応内容

### 1. 地図初期化の順序を調整

`js/app.js` の通常モード開始処理で、先に `showGame()` を呼んでゲーム画面を表示し、その後に `ensureMap()` を通すよう変更した。

目的:

- 非表示コンテナのまま Leaflet を初期化しない
- `invalidateSize()` が効く前提を崩さない

## 2. レイアウトの高さを明示

`css/style.css` で以下を調整した。

- `data-layout="left"` と `data-layout="right"` に `align-items: stretch` を追加
- `.map-slot` に `height: 100%` と `align-self: stretch` を追加
- `.map-panel` に `width: 100%` と `height: 100%` を追加

目的:

- サイドバー併用レイアウト時でも地図領域が親の高さを確実に引き継ぐようにする

## 3. Leaflet のコアルールを補完

`css/style.css` に、テーマ用の上書きで欠けていた Leaflet の基本ルールを一部戻した。

主な内容:

- overlay SVG / tile image の `max-width`, `max-height` の無効化
- `.leaflet-tile-loaded` の可視化ルール
- map pane / control の基本的な z-index, float, margin, transform-origin の補完

目的:

- 見た目のテーマを維持しつつ、Leaflet の標準描画挙動を壊さないようにする

## 確認方法

ローカルでは `file://` 直開きではなく、HTTP サーバー経由で確認する。

```powershell
cd G:\geoquiz-main\geoquiz-main
python -m http.server 8000
```

ブラウザ:

- `http://localhost:8000/` を開く
- 市区町村モードを開始する
- 地図が表示されることを確認する

## 補足

- 途中で一時的に `console.debug` を使って `Leaflet initialized` と `size` / `pathCount` を確認した
- 最終的にはデバッグログを削除してある
- 今回はデータ欠損ではなくレイアウト不具合だったため、過去状態へ戻さずに修正で解決した

## 追加対応（同日）

地図表示復旧後、ゲームHUDと音声周りで見つかった不具合・改善要望にも対応した。

### 4. 問題名の可読性を改善

症状:

- サイドパネルで `蕨市` など短い地名がつぶれて見えることがあった
- 見出しに使っていたフォントが日本語地名表示に強くなかった

対応:

- `css/style.css` で通常の地名見出しを `Zen Kaku Gothic New` ベースへ変更
- `font-weight`, `line-height`, `overflow-wrap` を調整
- MAモードの数字表示は従来どおり `Dela Gothic One` を維持

目的:

- 市区町村名を自然に読める見た目へ寄せる
- 数字系モードのインパクトは残す

### 5. 上バー時のポリゴンプレビュー未表示を修正

症状:

- `top` レイアウトで上バーに切り替えた時、問題ポリゴンプレビューが出ない

原因:

- `referencePreviewTop` には SVG を流し込んでおらず、サイドパネル側の `referencePreview` だけを更新していた

対応:

- `js/app.js` の `updateReferencePreview()` で、上バー用 `referencePreviewTop` にも同じ SVG を反映するよう変更

### 6. 上バーの幅配分を見直し

症状:

- 上バーで問題名の領域が狭く、プレビューやボタンとのバランスが悪かった

対応:

- `css/style.css` で上バーの `min-height`, `padding`, `flex` 配分を調整
- 問題名エリアの `flex-basis` と `min-width` を拡張
- 統計カード、操作ボタン、レイアウト切替は上バー専用で少しコンパクト化
- 上バーのポリゴンプレビューも少し広げた

目的:

- 問題名とポリゴンプレビューに優先して幅を返す
- HUD全体を一列の中で見やすく整える

### 7. `bottom` レイアウトを追加

要望:

- `left / top / right` があるなら `bottom` も欲しい

対応:

- `index.html` のレイアウト切替に `data-layout="bottom"` を追加
- `css/style.css` に `data-layout="bottom"` 用レイアウトを追加
- 実装は上バーと同じHUDを下側へ回す方式

結果:

- 地図を上に大きく取りつつ、情報バーを下に置けるようになった

### 8. 上下バー時のトグルをバー内へ移動

症状:

- `top` / `bottom` レイアウトでは `サドンデス` と `ミス音声` が地図上の左下に浮いて見えており、バーとの一体感が弱かった

対応:

- 上下バー共通で使うコンパクトトグルを `gameTopbar` 内へ追加
- 既存トグルと双方向同期するよう `index.html` の同期スクリプトを拡張
- `top-overlay-bottom` は `top` / `bottom` レイアウト時に非表示化

目的:

- 上下バーの情報をバーの中へ集約し、見た目の一貫性を出す

### 9. 音声トグルの意味を整理

要望:

- これまでの `ミス音声` という表記だと、正解時にも音が出る仕様に変えた後に意味が合わない

対応:

- `index.html` 上の各レイアウトで `ミス音声` を `音声` に変更

### 10. 正解時にも読み上げるよう変更

変更前:

- 不正解時のみ、地名または市外局番を読み上げていた

変更後:

- 正解時も不正解時も同じ読み上げ関数を通すように変更
- 市区町村モードでは地名
- 市外局番モードでは市外局番

実装:

- `js/app.js` のクリック時分岐で、正解時にも `speakAnswer()` を呼ぶようにした

### 11. 読み上げ補正テーブルを追加

症状:

- `東秩父村` が `ひがしちちちちぶむら` のように不自然に聞こえるなど、音声エンジンが日本語地名を正しく読めないケースがあった

対応:

- `js/app.js` に `speechLabelOverrides` を追加
- 地名読み上げ時はそのまま `name` を渡さず、補正関数を経由するように変更

追加した主な補正:

- `鴻巣市` → `こうのすし`
