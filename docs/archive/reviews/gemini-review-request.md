# Gemini CLIへの依頼文

Gemini CLIには、今後このプロジェクトの**レビューのみ**を依頼します。

## 依頼内容

以下の観点でコード・データ・ドキュメントを確認してください。

- 実装上のバグや壊れやすい箇所
- データ構造の矛盾
- 将来拡張時に詰まりそうな設計
- READMEや開発ドキュメントとの不一致
- テスト不足や検証観点の抜け

## 禁止事項

- ファイルを直接編集しないでください
- コード生成や修正パッチの適用はしないでください
- 仕様変更を勝手に決めないでください
- 実装作業、リファクタリング、データ移動、pushは行わないでください

## 出力してほしいもの

レビュー結果はMarkdownで作成してください。

- 良い点
- 問題点
- 優先度つき改善案
- 追加で確認すべき質問

レビュー文書は、必要に応じて `review.md` や `follow.md` のような名前で作成して構いません。ただし、Gemini CLIの役割はレビュー専任です。実装はCodex側で判断して行います。
