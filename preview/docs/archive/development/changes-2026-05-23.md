# 変更履歴 2026-05-23

## 概要

- 地図が黒いまま表示されない不具合を修正
- HUDの可読性とレイアウト切替UIを改善
- 音声読み上げを正解時にも対応
- 読み上げ誤読しやすい地名を補正

## 変更点

- 非表示状態で Leaflet を初期化しないよう順序を調整
- 地図コンテナの高さが `0` にならないようレイアウトCSSを修正
- Leaflet の基本描画ルールをテーマCSS内で補完
- 市区町村名の見出しフォントと幅配分を調整
- 上バーでポリゴンプレビューが出ない問題を修正
- 上バーの幅配分を見直し、問題名エリアを拡張
- `bottom` レイアウトを追加
- 上下バー時の `サドンデス` / `音声` トグルをバー内へ移動
- `ミス音声` 表記を `音声` に変更
- 正解時も地名・市外局番を読み上げるよう変更
- 地名の読み上げ補正テーブルを追加
- 開始前設定パネルと大きい `開始` ボタンを追加
- クイズ系モードを即開始から「選択して開始」へ変更
- 確認マップ系は即表示のまま維持
- 開始時に `3 → 2 → 1 → Start` カウントダウンを追加
- `リセット` を `リスタート` に変更し、現セッション内の設定保持で再開始可能にした
- クリア直後の即リザルト遷移をやめ、地図上の `Clear / Game Over` 終了オーバーレイを追加
- 終了オーバーレイから `分析 / TOP画面 / Xで投稿` へ遷移できるよう変更
- 失敗時は最後の誤答地点を `白枠 + 赤塗り` で強調表示
- 分析画面を `今回の結果` と `累積分析` に分けて再構成
- 分析画面に `一発正解` `前回比` `自己ベスト` を追加
- 右側の補助地図を小さくし、情報が1画面で追いやすい構成へ調整
- 分析画面に `戦績` セクションを追加し、同モード直近5回の推移を表示
