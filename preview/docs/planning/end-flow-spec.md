# 終了演出仕様 v1

## 目的

- クリア直後に即分析画面へ飛ばさず、達成感と次の行動を分かりやすくする
- `Clear` / `Game Over` を地図上で見せて、学習対象の位置を記憶に残しやすくする
- 詳細分析は既存リザルト画面へ分離する

## 終了フロー

1. 最終回答でゲーム終了
2. すぐに分析画面へ遷移しない
3. ゲーム画面上の地図に終了オーバーレイを表示する
4. `リスタート / 分析 / TOP画面 / Xで投稿` を選べる
5. `分析` を押したときだけ既存の分析画面へ遷移する

## クリア時

- タイトル: `Clear`
- 色味: 青緑系でさわやかな演出
- 表示項目:
  - `問題数`
  - `一発正解数`
  - `ミス`
  - `平均回答時間`
  - `クリアタイム`

## 失敗時

- タイトル: `Game Over`
- 色味: 落ち着いた赤系
- 表示項目:
  - `到達問題数`
  - `一発正解数`
  - `ミス`
  - `平均回答時間`
  - `経過時間`
- 最後に誤答した地点を地図上で `白枠 + 赤塗り` で強調する

## ボタン優先度

- 主ボタン: `リスタート`
- 補助ボタン:
  - `分析`
  - `TOP画面`
  - `Xで投稿`

## X 投稿テンプレ

### クリア時

```text
GeoQuiz 埼玉県 市区町村モード Clear
問題数 63 / 一発正解 41 / ミス 2 / 平均回答 4.2秒 / クリアタイム 05:28
#GeoQuiz #埼玉県
```

### 失敗時

```text
GeoQuiz 埼玉県 市外局番モード Game Over
到達問題数 6 / 一発正解 4 / ミス 1 / 平均回答 3.8秒
#GeoQuiz #埼玉県
```

## 補足

- 分析画面では既存の累積成績、ランキング、再出題導線を使う
- クリア直後のオーバーレイは地図を残したまま表示し、背景は少し暗くする
- 将来 `3ミス終了` モードを追加する場合も、この終了演出を共通利用できる構成にする
