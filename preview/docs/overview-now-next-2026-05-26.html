1. このアプリでやりたいこと

GeoQuiz は、GeoGuessr で「この地名はどこか」「この市外局番はどの地域か」を素早く思い出せるようになるための練習アプリです。

ただの地図クイズではなく、苦手を見つけて、そこだけ何度も練習できる ことが大事なテーマになっています。

目指している姿

  • 白地図を見ながら、地名と場所の結びつきを覚えられる
  • 市外局番や地域の特徴も一緒に覚えられる
  • どこを間違えやすいかを後から見返せる
  • 将来的には全国版や画像クイズにも広げられる
全国版を作るなら、いきなり全部を入れるのではなく、まずは 都道府県を当てる、 次に 市区町村を当てる、そのあとに 市外局番を当てる の順で進めるのが理想です。 これはかなり後半の段階の話です。

2. 今のアプリの大きな状態

かなり作り込まれている 試作というより、すでに遊べる学習アプリに近い段階です。
データが多い 現在は 63 データセットあり、県別や地方別の切り替えができます。
分析機能もある 結果保存、苦手ランキング、再出題などが入っています。
未整理の部分もある 文書では「ある」と読めるものが、現行コードではまだ表に出ていない箇所があります。
現在の主作業は UI 改善 いまは新機能追加より、スマホ横向きの使いやすさ調整を優先しています。

3. もうできていること

  • 市区町村クイズ
  • 市外局番クイズ
  • 一部データセットでのパズルモード
  • 確認用の地図表示
  • プレイ結果の保存
  • 苦手ランキング表示
  • 苦手だけ再練習する機能
  • ラベル位置を調整する編集モード
  • スマホ向けの軽量表示モード
つまり、「クイズを出す」だけではなく、「覚え直す」ための機能までかなり入っています。

4. まだ途中のこと

  • 画像判別モードはまだ未完成です
  • 全国版 japan_all は一度仮実装されたが、重すぎて実用的ではないため現状は外されています
  • 地方全域データセットは動くが、全国版だけは別格に重い状態です
  • 3桁までの広域市外局番専用モードは、現方針では採用していません
  • README などの説明文が、今の実物と少しズレています
いま一番困りやすいのは「説明を読むとできそうに見えるのに、実際にはまだ出ていない機能がある」ことです。
目安として、北海道全域では INP が 120ms 以下で収まる一方、日本全国版では 900ms 台まで悪化していました。 そのため、問題は「地方全域」ではなく「日本全国を一度に扱うこと」だと考えられます。

5. 今の問題は何か

今のGeoQuizは、機能が少なすぎるのではなく、むしろいろいろ増えてきたので整理が追いついていない状態に近いです。

大きく3つあります

  • 説明と実物のズレ: 文書には書いてあるが、今の画面ではまだ使えないものがある
  • 全国版の重さ: 地方全域は INP 120ms 以下で遊べるが、日本全国版は 900ms 台まで悪化した
  • 端末ごとの UI 調整: スマホ縦、スマホ横、PC、タブレットで見え方と操作感をそろえる必要がある

9. UI 調整の2周目で見る流れ

一通り「こういう UI にしたい」という形まで作れたら、次は自分以外のプレイヤーに通しで遊んでもらって調整します。

  1. TOPページを見る
  2. データセットを選ぶ
  3. 市区町村か市外局番を選ぶ
  4. ゲーム準備画面に進む
  5. プレイ中の画面を触る
  6. クリア時または失敗時の画面を見る
  7. 分析画面を見る
  8. ランキング画面を見る
つまり最終的には、1つの画面だけを良くするのではなく、最初から最後までの体験全体を整えることが目標です。

10. 機能面で次にやりたいこと

UI 調整と並行して、機能面では次の順番で考えている。

  1. サドンデスの見直し: 地図ありを選べてしまうなら、地図なし固定にする
  2. 画像モードの実装: まずは USA データセットで、州旗を見て州をクリックする形から考える
  3. 画像の種類を増やす: 州道標識、ナンバープレートを見て州をクリックする問題へ広げる
  4. ブラー版の追加: GeoGuessr でナンバープレートにはブラーがかかるため、ブラーありの練習モードも用意したい
画像モードは「ただ画像を出す」だけではなく、GeoGuessr の実戦に近い見え方まで寄せることが大事なポイントです。
