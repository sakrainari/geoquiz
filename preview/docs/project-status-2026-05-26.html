概要

GeoQuiz は、GeoGuessr 向けの地域認識トレーニングツールとして作られている静的 Web アプリ。 白地図をクリックしながら、市区町村や市外局番の位置関係を覚える構成になっている。

起動は index.html を直接開く方式で、アプリ本体はビルドレスのバニラ JavaScript。 ランタイム依存は軽く、地図描画に Leaflet、GeoJSON 処理に Turf.js、累積成績保存に localStorage を使っている。

README と実装の両方を見る限り、単なる地図クイズではなく「GeoGuessr 練習向けの学習ツール」として育てる方針が明確。

主要ファイル

  • index.html: UI 全体と Firebase ランキング初期化
  • js/app.js: 画面遷移、ゲーム進行、ランキング、分析
  • js/map-renderer.js: 地図描画、ラベル、パズル、ヒート表現
  • js/quiz-engine.js: 出題と正誤判定
  • js/progress-store.js: 累積成績保存と再出題用データ
  • data/catalog.js: データセット定義
  • tools/: データ生成、事前計算、検証、E2E テスト

実装済み機能

市区町村クイズ 地名から該当エリアを当てる基本モード。イージー、ノーマル、サドンデスのルール切り替えあり。
市外局番クイズ 局番エリア単位の判定に対応。結合済みポリゴンや局番ラベルの表示制御も入っている。
確認マップ / 分析画面 リザルト後に参照用の地図とランキングを確認できる。
パズルモード 市区町村ポリゴンをドラッグして正位置に戻す MVP 実装あり。ベストタイム保存も対応。
累積成績と再出題 苦手、前回ミス、未正解、最近ミス、低正答率などから練習セットを再構成できる。
ラベル調整モード ?edit=labels で専用 UI を開き、ドラッグ、角度調整、サイズ調整、JSON 書き出しができる。
