# GeoQuiz 今後の改善アイデアまとめ

## 最優先：動作安定
- 通常クイズの動作安定
- 市外局番モードの判定安定
- 誤クリック・二重クリック防止
- リセット処理の安定
- リザルト画面まで正常に完走できるようにする
- クリア後に完成地図を正しく再表示する

## ラベル調整モード
- URLパラメータ `?edit=labels` のときだけ起動
- 通常プレイヤーには非表示
- ラベルをドラッグ移動できるようにする
- 角度をスライダーで調整できるようにする
‐ フォントを選べるようにする
- サイズをスライダーで調整できるようにする
- ラベルON/OFF切替
- 市区町村ラベル、市外局番ラベルを別々に調整
- 調整結果を `label-overrides.js` またはJSON形式でコピーできるようにする

出力例：

{
  "04": {
    "point": [35.820000, 139.470000],
    "angle": -8,
    "size": 24
  }
}

## ラベル補正データ
- 自動計算だけでは限界があるため、県ごと又はエリア毎に補正データを持つ
- 例：`data/saitama/label-overrides.js`
- 将来的に東京、千葉、神奈川などを追加しやすくする

構成例：

data/
  saitama/
    label-overrides.js
  tokyo/
    label-overrides.js

## 市外局番ラベル改善
- 現在は市外局番ラベルが回転固定の場合がある
- 細長いエリアでは角度調整が必要
- 自動角度計算 + 手動補正を併用する
- 小さい地域はラベルサイズを自動で下げる
- 必要ならズーム時のみ表示

## パズルモード
- 東京など他県追加前に、埼玉でMVPを作る
- URLパラメータ `?mode=puzzle` またはトップ画面ボタンから起動
- 市区町村ポリゴンをドラッグ可能にする
- 正解位置に近づいたらカチッとスナップする
- 全ピースがハマったらクリア
- タイムアタック、効果音を追加

基本仕様：

- ポリゴンをバラバラに配置
- 正解位置の外枠を表示
- ドラッグ移動
- 一定距離以内でスナップ
- スナップ後は固定
- 完成判定
- リセットボタン

## ヒートマップ・学習データ
- セッション結果と累積学習データを分ける
- localStorageに累積保存
- JSONエクスポート/インポート対応
- データ破損時の復旧処理を入れる

保存データ例：

{
  "datasetId": "saitama",
  "version": 1,
  "updatedAt": "2026-05-19T12:00:00+09:00",
  "stats": {
    "tokorozawa": {
      "plays": 12,
      "correct": 9,
      "mistakes": 5,
      "lastPlayedAt": "2026-05-19T12:00:00+09:00",
      "lastMistakeAt": "2026-05-18T21:30:00+09:00",
      "totalAnswerMs": 84200
    }
  }
}

## ランキング・グラフ
- 苦手ランキング
- 正答率ランキング
- 平均回答時間ランキング
- 市区町村別ミス回数の横棒グラフ
- 正答率推移
- 回答時間分布
- 最初はChart.jsなしで、CSS横棒グラフで実装する

表示例：

苦手ランキング
1位 川口市　ミス12回　正答率58%
2位 飯能市　ミス9回　正答率64%
3位 秩父市　ミス8回　正答率70%

## 苦手練習モード
- 苦手だけ再出題
- 未正解だけ再出題
- 前回ミスした地域だけ練習
- 最近間違えた地域だけ練習
- 正答率が低い地域を優先出題

## スマホ軽量化/
‐ スマホ用のUI
- スマホではLite Modeを用意
- hover処理を無効化
- ラベル表示を簡略化
- tooltip大量生成を避ける
- shadowやblurを減らす
- アニメーションを減らす
- Turf.js unionを実行時に行わない
- 市外局番統合ポリゴンは事前生成JSON化する

方針：

PC: Full Mode
Mobile: Lite Mode
